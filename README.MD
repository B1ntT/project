## 🎯 Цель проекта

Модуль `processing` предназначен для обработки списков банковских операций, представленных в виде списка словарей. Он предоставляет удобные функции для:

- **фильтрации** операций по их статусу (`EXECUTED`, `CANCELED` и др.);
- **сортировки** операций по дате в нужном порядке (по убыванию или возрастанию).

Модуль может использоваться как часть более крупного приложения для анализа банковских транзакций, построения отчётов и выгрузок.

---

## ⚙️ Возможности

| Функция | Назначение |
|---------|-----------|
| `filter_by_state` | Фильтрация списка операций по значению ключа `state` |
| `sort_by_date` | Сортировка списка операций по значению ключа `date` |

Обе функции:
- не изменяют исходный список — возвращают **новый**;
- используют безопасные методы доступа к данным;
- имеют значения по умолчанию для опциональных параметров.

## 🚀 Использование

### Импорт модуля

```python
from processing import filter_by_state, sort_by_date
```

### `filter_by_state`

Фильтрует список словарей по значению ключа `state`.

**Сигнатура:**

```python
filter_by_state(data: list, state: str = 'EXECUTED') -> list
```

**Параметры:**

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `data` | `list` | — | Список словарей для фильтрации |
| `state` | `str` | `'EXECUTED'` | Значение ключа `state`, по которому идёт фильтрация |

**Возвращает:** новый список словарей с указанным статусом.

**Пример — статус по умолчанию `'EXECUTED'`:**

```python
from processing import filter_by_state

operations = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
]

result = filter_by_state(operations)
print(result)
# [
#   {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
#   {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
# ]
```

**Пример — статус `'CANCELED'`:**

```python
result = filter_by_state(operations, 'CANCELED')
print(result)
# [
#   {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
#   {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
# ]
```

### `sort_by_date`

Сортирует список словарей по значению ключа `date`.

**Сигнатура:**

```python
sort_by_date(data: list, reverse: bool = True) -> list
```

**Параметры:**

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `data` | `list` | — | Список словарей для сортировки |
| `reverse` | `bool` | `True` | `True` — убывание (от новых к старым), `False` — возрастание (от старых к новым) |

**Возвращает:** новый отсортированный список словарей.

**Пример — убывание (по умолчанию):**

```python
from processing import sort_by_date

sorted_ops = sort_by_date(operations)
print(sorted_ops)
# [
#   {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
#   {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
#   {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
#   {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
# ]
```

**Пример — возрастание:**

```python
sorted_ops = sort_by_date(operations, reverse=False)
print(sorted_ops)
# [
#   {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
#   {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
#   {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
#   {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
# ]
```

---

### Совместное использование

Функции легко комбинируются: например, можно сначала отфильтровать только исполненные операции, а затем отсортировать их по дате.

```python
from processing import filter_by_state, sort_by_date

executed_ops = filter_by_state(operations, 'EXECUTED')
sorted_executed = sort_by_date(executed_ops, reverse=False)

print(sorted_executed)
# [
#   {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
#   {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
# ]
```

## 🧱 Структура данных

Каждая операция представлена словарём со следующими ключами:

| Ключ | Тип | Описание |
|------|-----|----------|
| `id` | `int` | Уникальный идентификатор операции |
| `state` | `str` | Статус операции (`EXECUTED`, `CANCELED` и т. д.) |
| `date` | `str` | Дата операции в формате ISO 8601 (`YYYY-MM-DDTHH:MM:SS.ffffff`) |

**Пример:**

```python
{
    'id': 41428829,
    'state': 'EXECUTED',
    'date': '2019-07-03T18:35:29.512364',
}
```
